# Charm the Commuter — Forecast a City That Isn't

Entry for the [make.fun bounty "Charm the Commuter (forecast a city)"](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e): one line of weather, at most 140 characters, for a city that does not exist — naming the place, giving it weather, and making a bored commuter smile on the way to work.

## Entry

> Good morning, Puddleton: light rain, 16°C, and your bus is on time for once — even the clouds kept a promise.

(109 characters, one line.)

## How it works

`main.ts` (Node 22, TypeScript) writes the entry text to `/output/entry.txt`. Run it with:

```sh
node --experimental-strip-types main.ts
```
